📌 Overview Feed algorithms across modern social networks prioritize content that receives early interaction velocity within the first 60–120 minutes of publication. Posting outside an audience's active hours leads to severe algorithmic decay before the content can be surfaced to secondary viewer pools. Post Time Analyzer bridges empirical research with real-world verification: Live YouTube Extraction: Interacts directly with the Google YouTube Data API v3 to fetch exact views, likes, comments, and publication timestamps from any public video URL. Multi-Platform Support: Provides calibrated algorithmic models for Instagram, LinkedIn, and X (formerly Twitter). Dynamic Performance Diagnosis: Generates custom-tailored scheduling advice and next-post directives based on the specific metrics and timing of the analyzed link.

✨ Features Real-Time YouTube API Integration: Enter any valid YouTube video link to instantly inspect view counts, likes, comments, and exact upload timestamps. Cross-Platform Evaluation: Seamlessly switch between YouTube, Instagram, LinkedIn, and X with fluid segmented-control transitions. On-Demand Results Display: Clean initial landing state that reveals engagement metrics, graphs, and insights only after a post link is analyzed. Interactive Engagement Trends: Chart.js-powered spline curves illustrating 7-day relative audience engagement patterns for each platform. Performance-Tailored Insights Box: High-contrast analysis section diagnosing upload timing windows, calculating engagement ratios, and providing concrete tactical directives for upcoming posts. Zero Heavy Dependencies: Lightweight client-side application running purely on HTML, Tailwind CSS, and Vanilla JavaScript—no complex backend server setup required.

🛠️ Tech Stack Frontend: HTML5, Tailwind CSS Typography: Inter Data Visualization: Chart.js Logic & API Client: Vanilla JavaScript (ES6+ Fetch API) External Data Source: Google YouTube Data API v3

​📖 How It Works Select Platform: Choose between YouTube (Live API), Instagram, LinkedIn, or X. Paste Link: Enter a post or video URL into the input field (or click one of the provided sample links). Click Analyze: For YouTube, the app extracts the video ID and queries Google's Data API endpoint for live metadata and statistics. For Instagram, LinkedIn, and X, the app runs a calibrated benchmark simulation reflecting real-world platform engagement norms. Review Diagnosis: Timing Verdict: Checks whether the post landed in an optimal, moderate, or off-peak window. Engagement Rate: Computes Likes + Comments Views × 100 Views Likes+Comments​×100 and benchmarks it against typical platform baselines.
